# Tripleten web_project_around_es

# Descripción

Este proyecto es una página web interactiva donde los usuarios pueden agregar fotos, eliminarlas y darles me gusta, con un añadido de User Experience y escalabilidad por POO y TS.

# Funcionalidad

La página se diseñó con manejo de arreglos y funciones que permiten modificar el DOM mediante acciones del usuario por medio de formularios o interactuando haciendo clic en los iconos correspondientes a dar like o eliminar. Tiene como valor agregado la validación de formularios para que al momento de modificar el perfil el usuario pueda comprobar en tiempo real si el input que está dejando es válido y al mismo tiempo bloquea los botones hasta que el formulario tenga valores validos.
Actualización de POO: actualmente el código fue refactorizado en POO con typescript para que sea escalable y confiable, por lo que al retomar este proyecto más adelante es posible trabajarlo fácilmente.

# Oportunidades o planes de mejora

En un futuro se planea añadir un registro de correo y mediante una base de datos y APIs para acceder a lugares guardados dentro de la cuenta. Además de que hay mas implentaciones de UX/UI más alcanzables por medio de POO.
